기기에 저장하는 정보

AI 서비스로 보내는 요청

로그인·사용량 조회·warmup에는 선택한 서비스가 요구하는 인증정보를 해당 서비스로 전송합니다. 새로운 ChatGPT 구독 사용 등록에는 개인을 식별하지 않는 설치 식별자와 앱 이름도 사용합니다. warmup은 미리 정해진 짧은 모델 요청을 보내며 구독 사용량을 소비하거나 API 비용을 발생시킬 수 있습니다. 켜 둔 예약은 백그라운드에서도 요청을 실행할 수 있습니다. 각 서비스의 이용약관, 과금 규칙과 개인정보 처리방침이 적용됩니다. 연결한 AI 계정 정보와 인증정보는 AdMob 광고 요청에 포함하지 않습니다.

광고와 개인정보 선택

메인 탭 위의 배너에는 Google AdMob을 사용합니다. Google Mobile Ads SDK는 광고·분석·부정행위 방지를 위해 IP 주소, 기기·광고 식별자, 앱 상호작용과 진단 정보를 수집·공유할 수 있습니다. IP 주소로 대략적인 위치를 추정할 수 있습니다. 필요한 경우 Google UMP가 광고 요청 전에 개인정보 선택을 안내합니다. 선택 변경 항목이 필요한 사용자에게는 설정에서 해당 항목을 제공합니다. Android 기기의 광고 설정에서도 광고 식별자를 재설정하거나 삭제할 수 있습니다. 외부 업체가 보관하는 기간은 해당 업체의 정책을 따릅니다.

보관 기간과 삭제

연결한 인증정보·계정 설정·예약은 삭제하거나 교체할 때까지 기기에 보관합니다. 사용량 관측과 완료된 실행 기록의 기본 보관 기간은 90일이며 설정에서 30·90·180일을 선택할 수 있습니다. 결과 확인이 필요한 실행 기록은 검토할 때까지 보관합니다. 연결한 계정을 삭제하면 해당 계정의 인증정보와 관련 기기 내 사용량·실행 기록을 삭제합니다. 앱을 제거하면 앱 전용 저장 자료가 제거됩니다. 앱의 연결 삭제로 AI 서비스의 계정 자체가 삭제되거나 서비스가 이미 보유한 인증 승인이 철회되지는 않습니다. 접근 철회는 서비스의 공식 설정에서 진행하세요.
